# Projeto Conecta — Empatia e Cooperação

O **Projeto Conecta** é uma aplicação web responsiva desenvolvida para promover valores de empatia, escuta ativa e trabalho em equipe. A plataforma serve como uma landing page informativa e interativa para engajar pessoas em ações comunitárias e colaborativas.

---

## 🚀 Funcionalidades

* **Design Responsivo:** Layout adaptável para dispositivos móveis, tablets e desktops.
* **Navegação Suave:** Rolagem fluida (*smooth scroll*) ao clicar nos links do menu.
* **Animações de Scroll:** Efeito *Scroll Reveal* nos cards de conteúdo à medida que o usuário navega pela página.
* **Interface Moderna:** Estilização com gradientes, sombras suaves e tipografia legível.

---

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estruturação semântica do conteúdo.
* **CSS3:** Estilização, layout em Grid/Flexbox e animações.
* **JavaScript (ES6+):** Interatividade e manipulação do DOM via `IntersectionObserver`.
